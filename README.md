# 量子扫雷（Quantum Sweeper）

一个“有意思 + 新颖”的扫雷小游戏，基于原版玩法加入了：

- **首击必安全**，降低开局挫败感。
- **连击系统**：一次连锁开很多格会提升倍数，分数飞涨。
- **能量技能**：
  - `🔍 扫描`：消耗 100 能量，给出一个区域的雷/安全统计。
  - `⚡ 脉冲`：消耗 160 能量，随机净化一个地雷。
- **随机事件**：量子扰动会偶尔闪烁提示安全格，增加“惊喜感”。

## 运行方式

```bash
python3 -m http.server 8000
```

然后打开：<http://localhost:8000>

## 操作方式

- 左键：翻开格子
- 右键：插旗
- 控制栏：切换难度 / 新游戏 / 使用技能
